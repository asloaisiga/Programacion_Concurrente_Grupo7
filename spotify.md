# Spotify - Tareas concurrentes

## ¿Qué es Spotify?

Spotify es una aplicación que permite escuchar música y podcasts por internet. También permite descargar canciones para escucharlas sin conexión.

## ¿Cómo utiliza tareas concurrentes?

Spotify puede realizar varias operaciones al mismo tiempo. Por ejemplo, mientras una persona escucha una canción, la aplicación puede descargar otras canciones en segundo plano.

Esto permite que el usuario continúe escuchando música sin tener que esperar a que finalicen las descargas.

## Operaciones en segundo plano

- Descargar canciones y listas de reproducción.
- Cargar información de las canciones.
- Actualizar el progreso de las descargas.

## Ejemplo

Un usuario está escuchando su canción favorita y decide descargar una lista de reproducción. Spotify continúa reproduciendo la música mientras descarga las canciones.

## Conclusión

Spotify utiliza tareas concurrentes para mantener la reproducción de música mientras realiza otras operaciones, mejorando la experiencia del usuario.

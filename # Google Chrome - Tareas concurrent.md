# Google Chrome - Tareas concurrentes

## ¿Qué es Google Chrome?

Google Chrome es un navegador web que permite buscar información, visitar páginas, descargar archivos y utilizar aplicaciones en internet.

## ¿Cómo utiliza tareas concurrentes?

Chrome puede realizar distintas operaciones sin que una tenga que esperar a que termine la otra.

Por ejemplo, cuando descargamos un archivo, podemos continuar visitando otras páginas mientras la descarga se realiza en segundo plano.

## Operaciones en segundo plano

- Descargar archivos de internet.
- Cargar páginas web en diferentes pestañas.
- Actualizar contenido de páginas abiertas.

## Ejemplo

Un estudiante descarga un documento PDF desde una página web. Mientras el archivo se descarga, puede continuar investigando en otras pestañas sin interrumpir la descarga.

## Conclusión

Google Chrome utiliza tareas concurrentes para permitir que el usuario navegue y realice descargas sin detener sus actividades.
